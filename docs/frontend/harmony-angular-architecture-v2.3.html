1Executive summary

One Angular 22 workspace, two applications, libraries as plain folders with enforced boundaries, every token on the server, every claim tested. What is closed is closed on evidence; what is open is listed with the decision it waits for.

Platform

Angular 22.2.3 (active to 2027-06, LTS to 2028-06), TypeScript 6.0.3 (Angular accepts only >=6.0 <6.1), Node 24, pnpm 12.14. Zoneless, standalone, signals, OnPush.

Shape

One workspace at Frontend/web: apps harmony-web (hotel staff) and harmony-console (platform people), about 70 folder-libraries at full PMS scope, no per-library builds.

Security model

The existing YARP BFF holds every token. The browser holds one __Host- cookie, sends x-csrf: 1, runs under a per-request nonce CSP with Trusted Types enforced. The backend authorises every call.

Measured, not assumed

A throwaway Angular 22.2.3 workspace proved: nonce CSP + Trusted Types with zero violations, deep links under base-uri 'none', Arabic RTL build, zoneless tests, 78 KB initial shell, a zero-dependency boundary checker.

What changed my mind since v1 (all on evidence)

  • The BFF exists and is good. Steps 2.1–5 are committed: code + PKCE + PAR, private_key_jwt, sessions in Redis sealed by Data Protection, back-channel logout, refresh revocation, deny-by-default, CSRF header wall. The password grant is gone. repo: Backend/ApiGateways/Harmony.Web.Bff, commits 02f5d29…7259567
  • The BFF's page policy blocks Angular's styles. Served under today's exact style-src 'self', the spike app ran but every component style, the critical CSS and the stylesheet swap were blocked. A nonce-rendered index.html is required. spike: CSP mode "bff-today"
  • The idempotency receipt already works (Idempotency-Key, per tenant and user, 10-minute replay, 409 while in flight). framework: ReceiptGate.cs
  • Lost-update protection does not reach the UI. Row versions exist on entities but no API model exposes them. repo grep: no model carries RowVersion
  • Tenancy is simpler than v1 said. Tenant = the customer hotel company; one platform tenant (us) whose people never act inside a hotel; no Organisation layer, no support grants. Two apps, not one.
  • Three v1 dependency picks fail review: eslint-plugin-boundaries (pins handlebars 4.7.9 with two critical advisories), OpenTelemetry browser SDK (officially "experimental and mostly unspecified" in the browser), Lighthouse CI (no release for 15 months).
  • The Arabic typeface in the prototype (Dubai) is not part of Windows 11. Hotel PCs without it will render a different face. Microsoft Windows 11 font list; this PC has it installed

4Workspace and folder tree

One Angular CLI workspace, two application projects, and libraries that are plain folders with one index.ts each. Libraries are created when their first file is needed — never scaffolded empty.

Why folders, not built libraries

DEC Angular CLI library projects (ng-packagr) add a build, a version and a publish step per library. Harmony ships one product from one repository, so that cost buys nothing. A folder with an index.ts, a TypeScript path alias and an enforced boundary gives the same isolation. If a library must ever be shared outside this workspace, it graduates to a built package then, by ADR. IND Nx is the common alternative; it is rejected for now because its Angular plugin peers @angular/build <23 (would block the Angular 23 upgrade on Nx's schedule) and adds a second build system.

5.1 The rules

  1. Entry only. Another library is reached through @harmony/<group>/<lib>, which maps to its index.ts. Deep paths and relative paths that leave the library fail.
  2. Layers. feature → data-access, domain, own ui, ui, platform, shared · data-access → domain, platform, shared · domain → shared · ui → ui, shared · platform → platform, shared · shared → nothing.
  3. Cross-domain. Only a feature may use another domain, and only that domain's data-access entry. A check-in feature may call rooms and cashiering commands; the rooms domain never imports front office.
  4. Framework-free core. shared/* and every domains/*/domain import nothing from @angular/*, so the rules survive any framework upgrade and are tested in plain Node.
  5. App isolation. harmony-web never reaches platform-admin; harmony-console never reaches a hotel domain. The platform tenant rule ("platform people never act inside a hotel") is repeated in the code structure.
  6. No cycles between libraries.

5.2 How it is enforced

DEC tools/check-architecture.mjs: about 120 lines using only the TypeScript compiler the workspace already has. It parses static and dynamic imports, maps each file to its library, applies the rules above and finds cycles (Tarjan). spike: on a 10-library fixture it reported all 6 planted defects (relative escape, deep import, cross-domain into a non-entry, ui→data-access, @angular in a domain, a two-library cycle) and passed the cleaned tree with exit 0

Source of the checker as run in the spike (about 120 lines, Node + TypeScript only)
// Architecture fitness check, no dependencies beyond the TypeScript compiler the workspace already has.
// 1) every import between libraries goes through the target library's public entry (index.ts) via its @harmony alias
// 2) the layer rules (which library type may depend on which)
// 3) cross-domain imports only into another domain's data-access public API
// 4) no dependency cycles between libraries
// Exit code 1 on any violation; the report lists file, import and rule.
import ts from 'typescript';
import { readdirSync, readFileSync, statSync } from 'node:fs';
import { join, relative, sep } from 'node:path';

const root = process.argv[2] ?? '.';
const libsDir = join(root, 'libs');

// Library = folder that holds an index.ts directly under libs/<group>/<name> or libs/domains/<domain>/<type>.
function libraryOf(file) {
  const parts = relative(libsDir, file).split(sep);
  if (parts[0] === 'domains') return { id: `domains/${parts[1]}/${parts[2]}`, group: 'domain', domain: parts[1], type: parts[2].replace(/^feature-.*/, 'feature') };
  return { id: `${parts[0]}/${parts[1]}`, group: parts[0], domain: null, type: parts[0] }; // platform | ui | shared
}
function aliasToLibrary(spec) {
  // @harmony/<domain>/<type>  or  @harmony/<group>/<name>
  const m = /^@harmony\/([^/]+)\/([^/]+)(\/.*)?$/.exec(spec);
  if (!m) return null;
  const deep = Boolean(m[3]);
  if (['platform', 'ui', 'shared'].includes(m[1])) return { id: `${m[1]}/${m[2]}`, group: m[1], domain: null, type: m[1], deep };
  return { id: `domains/${m[1]}/${m[2]}`, group: 'domain', domain: m[1], type: m[2].replace(/^feature-.*/, 'feature'), deep };
}

// Who may depend on whom (by type). Same-domain rules; cross-domain is handled separately.
const allowed = {
  feature: ['data-access', 'domain', 'ui', 'platform', 'shared'],
  'data-access': ['domain', 'platform', 'shared'],
  domain: ['shared'],
  'ui-domain': ['domain', 'ui', 'shared'], // a domain's own ui library
  ui: ['ui', 'shared'],
  platform: ['platform', 'shared'],
  shared: ['shared'],
};
const typeKey = (lib) => (lib.group === 'domain' && lib.type === 'ui' ? 'ui-domain' : lib.type);

function* tsFiles(dir) {
  for (const name of readdirSync(dir)) {
    const p = join(dir, name);
    if (statSync(p).isDirectory()) yield* tsFiles(p);
    else if (p.endsWith('.ts') && !p.endsWith('.spec.ts')) yield p;
  }
}
function importsOf(file) {
  const source = ts.createSourceFile(file, readFileSync(file, 'utf8'), ts.ScriptTarget.Latest, true);
  const found = [];
  const visit = (node) => {
    if ((ts.isImportDeclaration(node) || ts.isExportDeclaration(node)) && node.moduleSpecifier && ts.isStringLiteral(node.moduleSpecifier)) found.push(node.moduleSpecifier.text);
    if (ts.isCallExpression(node) && node.expression.kind === ts.SyntaxKind.ImportKeyword && node.arguments[0] && ts.isStringLiteral(node.arguments[0])) found.push(node.arguments[0].text);
    ts.forEachChild(node, visit);
  };
  visit(source);
  return found;
}

const violations = [];
const graph = new Map();
for (const file of tsFiles(libsDir)) {
  const from = libraryOf(file);
  if (!graph.has(from.id)) graph.set(from.id, new Set());
  for (const spec of importsOf(file)) {
    if (spec.startsWith('.')) {
      // A relative import must stay inside its own library.
      const target = libraryOf(join(file, '..', spec));
      if (target.id !== from.id) violations.push([file, spec, 'relative import leaves its library; use the @harmony alias']);
      continue;
    }
    const to = aliasToLibrary(spec);
    if (!to) {
      // npm package: governed by the dependency registry; the pure layers stay framework-free.
      if (['domain', 'shared'].includes(typeKey(from)) && spec.startsWith('@angular/')) violations.push([file, spec, `${typeKey(from)} must stay framework-free (no @angular imports)`]);
      continue;
    }
    if (to.id === from.id) { violations.push([file, spec, 'a library imports itself through its alias']); continue; }
    graph.get(from.id).add(to.id);
    if (to.deep) violations.push([file, spec, 'deep import: only the library entry (index.ts) is public']);
    const crossDomain = from.domain && to.domain && from.domain !== to.domain;
    if (crossDomain) {
      if (!(from.type === 'feature' && to.type === 'data-access')) violations.push([file, spec, `cross-domain: only a feature may use another domain, and only its data-access`]);
      continue;
    }
    if (!allowed[typeKey(from)]?.includes(to.type === 'ui' && to.group === 'domain' ? 'ui' : to.type)) violations.push([file, spec, `${typeKey(from)} may not depend on ${to.type}`]);
  }
}

// Cycles between libraries (Tarjan's strongly connected components).
let index = 0; const stack = []; const meta = new Map(); const cycles = [];
function strong(v) {
  meta.set(v, { index, low: index, on: true }); index++; stack.push(v);
  for (const w of graph.get(v) ?? []) {
    if (!meta.has(w)) { strong(w); meta.get(v).low = Math.min(meta.get(v).low, meta.get(w).low); }
    else if (meta.get(w).on) meta.get(v).low = Math.min(meta.get(v).low, meta.get(w).index);
  }
  if (meta.get(v).low === meta.get(v).index) {
    const scc = []; let w;
    do { w = stack.pop(); meta.get(w).on = false; scc.push(w); } while (w !== v);
    if (scc.length > 1) cycles.push(scc);
  }
}
for (const v of graph.keys()) if (!meta.has(v)) strong(v);

for (const [file, spec, rule] of violations) console.log(`BOUNDARY  ${relative(root, file)}  '${spec}'  ${rule}`);
for (const c of cycles) console.log(`CYCLE     ${c.join(' -> ')}`);
console.log(`${graph.size} libraries, ${violations.length} boundary violations, ${cycles.length} cycles`);
process.exit(violations.length || cycles.length ? 1 : 0);

7.4 Signals, computed, linkedSignal, effects

  • Signals hold synchronous state; updates are immutable (update(list => [...list, x])).

8.2 Typography DEC (D19, approved 18 October 2026)

Both faces are local system fonts: nothing is downloaded, which is fast and licence-free, but the look depends on the PC. Evidence. The Dubai file on this PC (DUBAI-REGULAR.TTF, version 1.10, © 2016 Dubai Executive Council, made by Monotype) carries its licence in the font's name table: a "Microsoft supplied font" usable only under the terms of the Microsoft product it came with — "Any other use is prohibited." Invalidation

  1. My own write returns the new entity (and its version); the store patches it and marks dependent reads stale.
  2. Someone else's change arrives as a hub event naming property, entity, version and sequence; newer versions refetch or patch.

11.2 Rules the Angular app follows

  • Only relative URLs; every /bff and /api call carries x-csrf: 1; nothing reads or stores a token.
  • Sign-in and sign-out are top-level navigations (/bff/login?returnUrl= with a local path; logoutUrl from /bff/user), never fetch.

13.4 Techniques

  • OnPush + signals; computed for derivations; @for with stable track keys; no template method calls.
  • CDK virtual scroll for long lists; canvas for the timeline with a DOM focus layer; server paging/filtering above a few thousand rows.
  • Hub events queued and applied once per animation frame, deduplicated by entity, highest version wins.
  • Heavy pure computations (availability matrix) in the domain layer; above ~16 ms per frame, move to a Web Worker (CSP worker-src falls back to 'self').
  • Bounded caches: 20 entities per detail store, 5 pages per list query; cleared on property switch.
  • Theme/density switches are attribute changes on <html> (CSS variables), not re-renders.
  • Hashed assets immutable for a year; index.html no-store (nonce).

14.1 Retry rules

  1. GET: at most 2 automatic retries (0.5 s, 1.5 s + jitter) for network errors, 502, 503, 504.
  2. Writes with an Idempotency-Key: retry with the same key for network errors, 503 and 409 000.06, only within the server's 10-minute replay window.
  3. Writes without a key: never automatic. Payments: never re-sent; outcome queried.
  4. 401, 403, 400, 202, 422: never retried as such.

14.2 Logging and correlation

Each request carries a W3C traceparent from our interceptor. Client reports contain error kind, code, route pattern (/p/:property/front-office/check-in, not values), release, browser, correlation id — never names, document numbers, card data, free text or tokens.

26.2 Rules added to the Harmony skill (no decision needed)

  • Privacy by screen: minimisation per role, purpose text on guest-data forms, retention visible, no personal data in URLs, logs, telemetry or storage.
  • Images: NgOptimizedImage for content images, priority on the LCP image; user images only via <img>.
